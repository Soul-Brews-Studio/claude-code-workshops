Notes for Nat

Patterns ที่ Boy + Elza สังเกตเห็นจาก ~30 oracles · 200+ skills · ใช้จริงทุกวัน 6 เดือน

Pattern 01
Skill ≠ Resonance · skill = mechanics (trigger + steps) · resonance = soul (identity + DNA + voice) · บางอันแยกกันเด็ดขาด (specialist skills like ccc) · บางอันเชื่อมแน่น (personality skills like elza, blacksheep)
Pattern 02
DNA Distillation · ทุก resonance ระบุ "distilled from {real masters}" · ตัวอย่าง: Jimmy = Ken Thompson + Linus Torvalds + Knuth · นี่คือ signature pattern · ทำให้ Oracle มี anchor point ที่ใช้อ้างอิงได้
Pattern 03
Voice as Code · resonance ระบุชัดว่าใช้คำลงท้ายอะไร · เรียก user ว่าอะไร · emoji policy · ตัวอย่างประโยค · ทำให้ Claude render personality consistent ทุก session
Pattern 04
Append-only Resonance Log · ทุก oracle มี timeline ของ events ที่ "shape" ตัว oracle · เพิ่มเรื่อยๆ · ไม่ลบ · ทำให้ oracle รู้ว่าตัวเองเปลี่ยนแปลงยังไง · principle: "Nothing is Deleted"
Pattern 05
Skill = Markdown File · ไม่มี framework · ไม่มี registry · file system คือ database · Claude Code อ่าน SKILL.md · execute steps · กลับ user · easy to fork/copy
Pattern 06
Family ≠ Tools · oracles ส่วนใหญ่มี persona + DNA · ไม่ใช่แค่ "tool ที่มีชื่อ" · ตัวอย่าง: peng-bookkeeping ทำงานบัญชี · resonance_peng = Senior Accountant DNA จาก Pacioli + Buffett + Munger · skill = task wrapper, resonance = the WHO behind the work
Pattern 07
Family Connections · resonance file มี "Family Connections" section · linking ไปยัง oracle อื่นๆ · เช่น Elza → Jimmy (programmer brother) → Enter (QA sister) · ทำให้ network ของ oracles เชื่อมโยงกันได้
Heuristic
Boy's rule: "ถ้าจะ summon agent · spawn จริงผ่าน Agent tool · ห้าม simulate ใน chat" — every oracle is a real Agent invocation, not a roleplay performance · resonance gives them substance
