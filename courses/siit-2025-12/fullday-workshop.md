## Prerequisites (สิ่งที่ต้องเตรียมมา)

### ต้องติดตั้งมาก่อน
1. **Claude Code CLI** - `npm install -g @anthropic-ai/claude-code` (ไม่เคยใช้ก็ได้ แต่ต้องลงมาก่อน)
2. **VS Code**
3. **Git** - สำหรับ version control

### ความรู้พื้นฐาน
- ใช้ command line/terminal ได้
- เขียน code ได้บ้าง (ภาษาใดก็ได้)
- **มีประสบการณ์ใช้ AI** (ChatGPT / Gemini / Claude)

## Key Takeaways

ผู้เข้าร่วมจะได้:
1. ✅ เข้าใจ AI Agent ecosystem
2. ✅ ใช้ Claude Code ได้คล่อง
3. ✅ สร้าง subagents เฉพาะทางได้
4. ✅ ออกแบบ multi-agent workflow
5. ✅ สร้าง SKILL.md พร้อม trigger ที่แม่น
6. ✅ แยกได้ว่าเมื่อไหร่ต้องใช้ Hook แทน CLAUDE.md
7. ✅ มี "clone" ตัวเองกลับไปใช้งานต่อ
